Computation graph có SAE: node nằm ở đâu, edge nối cái gì

Model thu nhỏ, đã giảm chiều cho dễ hiểu: 2 layer (Pythia-70M: 6), 2 token, mỗi SAE vẽ 3 feature + 1 ε (Pythia: 32 768 feature + 1 ε). Layer vẽ theo dạng tuần tự Attn → MLP như đã học. Paper §3.1, App. A.1, A.3.

1. Trước và sau khi viết lại x

Trước: SAE chỉ đọc ra, model không dùng

x → layer sau
x → SAE encoder → f (ghi ra ngoài)

Layer sau nhận x (activation) trực tiếp. fᵢ (feature activation) chỉ là con số tính bên cạnh. Sửa fᵢ thì layer sau không thấy gì, m (metric) không đổi, và ∂m/∂fᵢ không tồn tại vì m không phụ thuộc vào fᵢ.

Sau: x được tính lại từ f và ε

x → encoder → f, ε = x − x̂
x ← Σ fᵢ·vᵢ + b + ε → layer sau

Giá trị x giống hệt cũ (đẳng thức đúng tuyệt đối). Nhưng giờ layer sau đọc x được tính từ fᵢ và ε. Sửa fᵢ → x đổi → layer sau đổi → m đổi. PyTorch autograd tính được ∂m/∂fᵢ và ∂m/∂ε.

Ví dụ 2 chiều: v₁ (feature 1) = [1, 0], f₁ = 2, ε = [0.1, 0.3], b = 0. x = 2·[1,0] + [0.1,0.3] = [2.1, 0.3], đúng bằng x thật. Patch f₁ = 0 → x = [0.1, 0.3], layer sau nhận vector này. Gradient: ∂x/∂f₁ = v₁ = [1, 0], nên ∂m/∂f₁ = (∂m/∂x)·v₁ (App. A.3).

Chi tiết kỹ thuật trong App. A.3: paper đặt stop-gradient lên ε. Nếu không, x = x̂ + (x − x̂) làm gradient theo fᵢ triệt tiêu về 0.

2. Ba chỗ có SAE trong một layer (1 token)

3. Bên trong một ô SAE: node nằm ở đâu

Ví dụ dùng v₁ = [1, 0] (cột 1 của decoder) và b = 0, nên decoder ra x̂ = 2·[1, 0] = [2, 0]. Mỗi chấm xanh là 1 node (1 số). Ô cam ε là 1 node (1 vector). x̂ chỉ là tổng của các feature (f₁·v₁ + f₂·v₂ + …), nên x̂ không phải node riêng: tác động của x̂ đã được chia ra cho từng fᵢ.

Trong mạng ở phần 4, mỗi hộp nhỏ chính là một ô SAE như hình này, chỉ vẽ gọn còn f₁, f₂, f₃ và ε.

4. Node trong mạng: mỗi chấm là một node

Chấm xanh dương = feature activation fᵢ (1 số). Chấm cam vuông = SAE error ε (1 vector 512 số, nhưng tính là 1 node). Mỗi hộp = 1 SAE tại 1 token. Hộp xám = embedding (Pythia có SAE ở embedding, Gemma không).

5. Edge là gì (App. A.1)

Edge nối node phía trước u với node phía sau d. Trọng số của edge = effect lên m khi patch u, nhưng chỉ phần đi thẳng qua d: mọi node trung gian giữa u và d bị giữ ở giá trị clean.

Ví dụ: u = feature ở resid layer 0, d = feature ở resid layer 1. u ảnh hưởng d theo 3 đường: thẳng qua residual connection, qua Attn₁, qua MLP₁. Edge u → d resid₁ chỉ đo đường thẳng; hai đường qua Attn₁, MLP₁ là các edge u → attn₁, u → mlp₁ riêng.

IE(edge) ≈ ∇_d m · ∇_u d · (u_patch − u_clean) (Eq. 5)

∇_d m (gradient của m theo d) · ∇_u d (gradient của d theo u, các node trung gian coi là hằng số) · (u_patch − u_clean) (mức thay đổi của u). Đây là AtP áp dụng cho 2 node nối tiếp.

EdgeLý do có edge
resid ℓ−1 → attn ℓ, mlp ℓ, resid ℓattn ℓ và mlp ℓ đọc residual stream; resid ℓ = resid ℓ−1 + attn + mlp
attn ℓ → mlp ℓ, resid ℓattn output được cộng vào x trước khi MLP đọc
mlp ℓ → resid ℓmlp output được cộng vào cuối layer
resid ℓ−1 token trước → attn ℓ token sauattention là bước duy nhất đọc token khác (chỉ token trước)
