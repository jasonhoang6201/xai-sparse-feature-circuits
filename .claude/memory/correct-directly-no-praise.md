When the user restates their understanding, do not open with "Bạn hiểu đúng…" or list the correct parts. Go straight to what is wrong and fix it, in a two-person conversation tone (short back-and-forth, plain sentences), not a structured report with "Phần đúng / Chỗ 1 / Chỗ 2" headings.

**Why:** the user said: "không có nói là luồng bạn đúng hay gì, vô chỉnh luôn những chổ tôi sai, giống như trò truyện 2 người để đảm bảo là tôi hiểu".

**How to apply:** quote or paraphrase the wrong part, then say what it actually is, with a small number if useful. If everything is right, one short line ("Đúng.") and move on. Still end with the next-concept question from [[one-concept-at-a-time]].
